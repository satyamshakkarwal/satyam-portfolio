# Satyam Shakkarwal — Portfolio

Personal portfolio of Satyam Shakkarwal, Shopify Expert & Framer web developer.

Static site (plain HTML / CSS / JS, no build step).

## Structure
- `index.html` — home
- `projects.html` — all work
- `project.html` — data-driven case-study page (`?p=slug`)
- `about.html`, `contact.html`, `404.html`
- `assets/css/style.css`, `assets/js/main.js`
- `assets/img/` — logos & project screenshots

## Local preview
Open `index.html` in a browser, or run a static server:

```bash
npx serve .
```

## Deploy
Hosted on Netlify. Pushing to `main` triggers an automatic deploy.
